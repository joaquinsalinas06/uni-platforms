# Bienvenido a tu Nueva Plataforma

Esta plataforma fue generada a partir de la arquitectura modular **uni-platforms**.

## ¿Cómo agregar contenido?
1. Escribe tus notas y explicaciones en formato Markdown / MDX en esta carpeta `content/topics/`.
2. Para añadir diagramas, simulaciones de circuitos, grafos o árboles, simplemente declara el bloque `visualization` en el frontmatter o incluye componentes interactivos.

## Visualizaciones disponibles
Puedes usar cualquiera de las 11 familias universales compartidas:
- `tree` (Árboles binarios, AVL, Segment Tree)
- `persistent` (Estructuras persistentes, Fat Nodes, Path Copying)
- `circuit` (Circuitos con resistencias, fuentes y solver nodal KVL)
- `dag` (Grafos dirigidos acíclicos y paralelismo)
- `timeline` (Líneas de tiempo, hilos y pipelines)
- `memory-layout` (Disposición de memoria y cachés)
- `flow` (Diagramas de flujo con formas geométricas)
- `sequence` (Diagramas de secuencia temporal)
- `xy-chart` (Gráficos matemáticos)
