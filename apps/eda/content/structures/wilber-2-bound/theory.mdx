## ¿Qué problema resuelve?

El teorema de [rectángulos independientes](/structures/independent-rectangles-bound) da una cota inferior, pero depende de $\mathrm{MIS}$, que es NP-difícil. Hace falta una cota
**calculable en tiempo polinomial** que aun así sea una cota inferior de verdad. Wilber-2 es la primera de las dos que salen de ese método (#35).

## Intuición

Mira cada acceso $p$ mirando hacia atrás en el tiempo, pero sólo a los accesos que **"ve"**: aquellos con los que forma un rectángulo vacío. Si esos accesos visibles caen alternadamente a la izquierda y a la derecha de $p$
mientras retrocedes en el tiempo, cada cambio de lado es un rectángulo independiente más: el algoritmo no pudo haber dejado "preparado" a $p$ para ambos lados a la vez sin pagar.

## Estructura interna

**Idea de análisis (#36).** Para cada punto $p$ de la entrada: mira los puntos **visibles hacia abajo** (aquellos cuyo rectángulo con $p$ no contiene ningún otro punto), **ordenados por tiempo decreciente**, y cuenta las
**alternancias de signo** de su posición respecto de $p$ (a la izquierda o a la derecha de la llave de $p$).

**La cota (#37).** La suma de esas alternancias, sobre todos los puntos $p$ de la entrada, es una cota inferior de $\mathrm{OPT}$: cada alternancia da un rectángulo independiente más.

> **Nota de apoyo** (no está en las diapositivas): la diapositiva habla de "alternancias de signo en $y_i - p$"; en los dibujos de la clase la llave es el eje horizontal, así que aquí se lee como el signo de $(\text{llave}_i - \text{llave}_p)$.

```cpp
// seq[t-1] = llave accedida en el tiempo t. Devuelve Wilber-2 de la secuencia.
int wilber2(const vector<int>& seq) {
  int m = seq.size(), total = 0;
  for (int t = 1; t <= m; t++) {
    int k = seq[t - 1], signo_ant = 0;
    for (int s = t - 1; s >= 1; s--) {            // tiempo decreciente
      int k2 = seq[s - 1];
      if (k2 == k) continue;
      bool visible = true;                         // ¿algún otro punto de la entrada en el rectángulo?
      for (int u = s + 1; u < t && visible; u++)
        if (min(k, k2) <= seq[u - 1] && seq[u - 1] <= max(k, k2)) visible = false;
      if (!visible) continue;
      int signo = k2 > k ? +1 : -1;
      if (signo_ant != 0 && signo != signo_ant) total++;
      signo_ant = signo;
    }
  }
  return total;
}
```

## Operaciones

Este tema no tiene operaciones. Lo que se calcula es la cota (arriba) y se enuncian dos resultados adicionales sobre ella.

## Análisis de complejidad

**Resultados adicionales (#40–#42).**

- *Conjetura:* se cree que $\text{Wilber-2} = \Theta(\mathrm{OPT})$. **Abierto**: ¿es $\mathrm{OPT} = \Theta(\text{Wilber-2})$?
- *Optimalidad llave-independiente (Iacono, 2005):* si las llaves fueran "sin significado" (se podrían permutar al azar), entonces $\mathrm{OPT} = \Theta(\text{cota del conjunto de trabajo})$ —por lo tanto, **los Splay Trees son óptimos llave-independientes**.
- *El porqué (esbozo):* $\mathbb{E}[\text{Wilber-2}(x_i)] = \Theta(\lg t_i)$: el número esperado de cambios de máximo bajo una permutación aleatoria ya es la cota del conjunto de trabajo ($t_i$: llaves distintas accedidas desde el último acceso a $x_i$).

El costo de calcular la cota con el código de arriba es $O(m^3)$ por ser literal; un cálculo con estructuras de datos es más rápido, pero el profesor no lo da.

| | Wilber-2 | [Wilber-1](/structures/wilber-1-bound) |
|---|---|---|
| Depende de | Sólo de la secuencia | De un árbol de referencia fijo $P$ |
| Qué cuenta | Alternancias entre puntos visibles desde cada acceso | Alternancias izquierda/derecha en cada nodo de $P$ |
| Uso en la clase | Splay Trees llave-independientes | Tango Trees ([tango-tree](/structures/tango-tree)) |
