En el modelo RAM son indistinguibles

¿Y en la máquina real?
El arreglo aprovecha cada bloque completo. La lista puede necesitar un
bloque nuevo por cada nodo. Necesitamos un modelo que vea esa diferencia.

    Los parámetros


Tres números
 ▶ N: el tamaño de la entrada (en palabras).
 ▶ M: lo que cabe en memoria.
 ▶ B: el tamaño de un bloque.
Suponemos 1 ≤ B ≤ M/2 y, para que el problema sea interesante, N > M.

¿Qué es “memoria” y qué es “disco”?
Lo decide la escala del problema. Para una base de datos, la memoria es la
RAM y el disco es el disco. Para una simulación que cabe en RAM, la
“memoria” es la caché L2 y el “disco” es la RAM.

  El modelo aproxima el salto más lento de la jerarquía, que es el que domina el
        tiempo. También se le llama modelo de E/S o Disk Access Model.

Cómo leer la tabla
Escanear gana un factor B. Buscar cambia la base del logaritmo de 2 a B.
