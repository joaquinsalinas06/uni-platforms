Cada nodo guarda min y max.

    Sucesor en un X-fast tree


Algoritmo 1: Sucesor-X(x)
lo ← 0, hi ← w                   // el prefijo de longitud 0 siempre está
mientras lo < hi hacer
    mid ← ⌈(lo + hi)/2⌉
    si (mid, x ≫ (w − mid)) ∈ T entonces
         lo ← mid
    en otro caso
         hi ← mid − 1
ℓ ← lo, p ← x ≫ (w − ℓ)
si ℓ = w entonces devolver sig (x)            // x ∈ S: el siguiente de la lista

si el bit ℓ + 1 de x es 0 entonces
     devolver T [(ℓ + 1, 2p + 1)].min          // falta el hijo izquierdo
en otro caso
     y ← T [(ℓ + 1, 2p)].max // falta el hijo derecho: y es el predecesor
     devolver sig (y )

    Insertar y eliminar




Insertar(x)
Buscar el sucesor con Sucesor-X para ubicar a x en la lista y agregar los
w + 1 prefijos de x a T , actualizando min y max de los que ya existían.

Eliminar(x)
En cada prefijo de x: si x era la única llave, se borra la entrada; si era el min
(o el max), el nuevo valor es el siguiente (o el anterior) de x en la lista.

Algoritmo 3: Sucesor-Y(x)
rj ← el mayor representante ≤ x (consulta al X-fast tree)
si hay una llave > x en el BST de Gj entonces devolver la menor de ellas

O(lg w ) + O(lg w ) = O(lg w )
La búsqueda de rj es del X-fast tree; las demás búsquedas son en BST de

    Cada cuánto se reestructura




Tras una partición o fusión, ¿cuántas actualizaciones hacen falta en
ese grupo para que haya otra?

Al menos w /4
 ▶ Partición de 2w + 1: grupos de tamaño w y w + 1. Para volver a 2w + 1
   hacen falta ≥ w inserciones; para bajar de w /2, ≥ w /2 eliminaciones.
 ▶ Fusión: el resultado mide ≥ w − 1 y, si supera 1,5w , se parte en grupos
   de (0,75w , 1,25w ): para llegar a 2w o a w /2 hacen falta ≥ w /4
   operaciones.

    La cota amortizada




Teorema
Insertar y Eliminar cuestan O(lg w ) amortizado.

Demostración
Cada operación paga O(lg w ) por la búsqueda en el X-fast tree y el BST.
Una reestructuración cuesta O(w ) y ocurre a lo más una vez por cada w /4
operaciones de ese grupo: se cobra O(w )/(w /4) = O(1) a cada una. Total:
O(lg w ) + O(1).
