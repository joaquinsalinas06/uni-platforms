## Pregunta 1 — Multiplicación de matrices (2 pts, con Tarea 0.5 pts/paso)

Considere el siguiente DAG que calcula el elemento $C_{i,j}$ de la matriz $C = A \times B$ para $n=4$.

Gráfica: DAG de dos niveles — 4 nodos de multiplicación $A(i,1)B(1,j)$, $A(i,2)B(2,j)$, $A(i,3)B(3,j)$, $A(i,4)B(4,j)$ que alimentan, en pares, dos sumas parciales, y éstas alimentan a una suma final que produce $C(i,j)$.

Generalice el problema para el cálculo del producto matricial de dos matrices $n \times n$, utilice el método de Foster para optimizar el algoritmo.

Aplique una **descomposición funcional** (de tareas). Siga los pasos de: **particionamiento** (defina adecuadamente la tarea primitiva), **comunicación** (cantidad de canales entre tareas creadas), **aglomeración** (cantidad de sub-matrices para cada tarea), y **mapping** (cantidad de procesos necesarios). (0.5 pts/paso)

Considere el problema para $n=10^9$, y que cada proceso puede calcular, como máximo, una sub-matriz de $10^3 \times 10^9$ elementos, debido a limitaciones de memoria.

### Solución

**Método de Foster:**

- **Particionamiento:** se puede iniciar definiendo una tarea por cada celda de la malla (cada multiplicación elemental). La tarea consiste en multiplicar dos elementos de la matriz, i.e. $10^{18}$ tareas.
- **Comunicación:** para esta cantidad de tareas, se necesita un número proporcional de canales de comunicación ($10^{18}$), ya que por cada fila, se deben sumar los productos para obtener un valor $C_{ij}$.
- **Aglomeración:** para reducir canales de comunicación, se pueden aglomerar las tareas por filas de $10^9$ elementos cada una, lo que reduce la cantidad de canales de comunicación a $10^9$.
- **Mapping:** sin embargo, cada proceso puede calcular, como máximo, una sub-matriz de $10^3 \times 10^9$ elementos, lo que define $10^{18}/10^{12} = 10^6$ procesos, y una cantidad proporcional de canales de comunicación.

## Pregunta 2 — Escalabilidad (1 pt)

El algoritmo de Floyd (para el cálculo de rutas más cortas en un grafo) tiene una complejidad

$$T_p = T_{comp} + T_{comm} = O\left(\frac{n^3}{p}\right) + O\left(\frac{n^2}{\sqrt{p}}\log p\right)$$

donde $n$ es la cantidad de nodos y $p$ la cantidad de procesos.

#### (a) Determine el speedup y eficiencia del algoritmo ¿Cómo depende el número de procesos $p$ de la cantidad de elementos $n$, si el speedup tiene una complejidad ideal ($S=O(p)$)? (0.3 pts)

#### (b) Con 16 procesos, se resuelve un grafo de $2^{10}$ nodos a una alta eficiencia. Se quiere procesar un grafo de $2^{20}$ nodos ¿Cuántos procesos se necesitan para mantener la eficiencia constante? **Nota:** derive una expresión para la eficiencia y encuentre la condición para $E=O(1)$ (0.5 pts)

#### (c) Bajo esa condición ¿Qué tipo de escalabilidad muestra el algoritmo de Floyd? (0.2 pts)

### Solución

El tiempo total paralelo es

$$T_{comp} + T_{comm} = O\left(\frac{n^3}{p}\right) + O\left(\frac{n^2}{\sqrt{p}}\log p\right)$$

#### (a)

Ya que $T_s = O(n^3)$,

$$S = O\left(\frac{n^3}{\frac{n^3}{p}+\frac{n^2}{\sqrt{p}}\log p}\right)$$

$S=O(p)$ equivale a la condición $E=O(1)$. Con

$$E = O\left(\frac{1}{1+\frac{\sqrt{p}\log p}{n}}\right)$$

se obtiene $n \propto \sqrt{p}\,\log(p)$.

#### (b) y (c)

Ya que $n$ crece con $p$, se trata de un caso de escalabilidad débil. La condición $n \propto \sqrt{p}\,\log(p)$ define la relación entre ambas variables: para mantener $E=O(1)$ al pasar de $n_1=2^{10}$, $p_1=16$ a $n_2=2^{20}$, el número de procesos $p_2$ debe satisfacer $\dfrac{n_1}{n_2} = \dfrac{\sqrt{p_1}\log p_1}{\sqrt{p_2}\log p_2}$ — un caso de escalabilidad débil, análogo al ejercicio del ordenamiento por ranking.

## Pregunta 3 — DAG (2 pts)

Dado el siguiente código:

```c
double function() {
  int i, n, j;
  double *v, *w, *x, *y, *z, sw, res;
  scan(&n, &v, &w, &x, &y, &z); /* Leer los vectores v, w, x, y, de dimension n*/

  modifica_v(n,y);              // Tarea 1, O(n log(n))
  modifica_w(n,w);              // Tarea 2, O(n^2/log(n))
  modifica_z(n,z);               // Tarea 3, O(log(n))
  /* Tarea 4*/
  for (j=0; j<n; j++){
    sv=0;
    for (i=0; i<n; i++) sv=sv+v[i]*w[i];
    for (i=0; i<n; i++) v[i]=sv+v[i]; }
  /* Tarea 5*/
  for (j=0; j<n; j++){
    sw=0;
    for (i=0; i<n; i++) sw=sw+w[i]*z[i];
    for (i=0; i<n; i++) z[i]=sw*z[i]; }
  /* Tarea 6*/
  sx=0;
  for (j=0; j<n; j++) y[j]=sx*z[j];
  /* Tarea 7*/
  x=sv*sw;
  for (i=0; i<n; i++) res = res+x*z[i]+x*y[i];
  return res;
}
```

#### (a) Diagrame el DAG correspondiente al código (no paralelice internamente las tareas) (0.4 pts)

#### (b) Determine $T_s$, $T_\infty(n)$, $W(n)$, $S(n)$. Considere que $T_p = T_{comp} + T_{comm}$, donde $T_{comm} = O(\beta\cdot x)$, siendo $x$ la data que es copiada de función a función. E.g. $T_1$ envía el vector $v$, de tamaño $n$, a $T_4$, por lo que $T^{1,4}_{comm} = O(\beta\cdot n)$. El factor $\beta$ representa el ancho de banda o velocidad de envío por Byte. No simplifique términos de complejidad (0.8 pts)

#### (c) Optimice el paralelismo según Foster (aglomeración) y vuelva a calcular $T_s$, $T_\infty(n)$, $W(n)$, $S(n)$ ¿Cuál algoritmo tiene mayor performance (velocidad)? (0.8 pts)

### Solución

Nodos: $T_1$ ($O(n\log n)$), $T_2$ ($O(n^2/\log n)$), $T_3$ ($O(\log n)$), con aristas $T_1 \xrightarrow{v} T_4$, $T_2 \xrightarrow{w} T_4$, $T_2 \xrightarrow{w} T_5$, $T_3 \xrightarrow{z} T_5$; $T_4$ ($O(n^2)$) y $T_5$ ($O(n^2)$) alimentan a $T_6$ ($O(n)$) y $T_6 \xrightarrow{y} T_7$ ($O(n)$).

#### (b) Métricas (sin optimizar)

$$T_s(n) = O(n^2 + n + n\log n + n^2/\log n + \log n)$$

$$T_\infty(n) = O(n^2/\log n + n^2 + n)$$

$$T_{comm} = O(n\beta) \quad\text{(se ignora envío de elementos simples)}$$

$$T_p = O(n\log n + n^2 + n + n\beta)$$

$$S(n) = O\left(\frac{n^2+n+n\log n+n^2/\log n+\log n}{n\log n+n^2+n+n\beta}\right)$$

#### (c) Optimización (aglomeración)

Si aglomeramos de esta forma:

$$T_s(n) = O(n^2 + n + n\log n + n^2/\log n + \log n)$$

$$T_\infty(n) = O(n^2/\log n + n^2 + n)$$

$$T_{comm} = O(n\beta) \quad\text{(se ignora envío de elementos simples)}$$

$$T_p = O(n\log n + n^2 + n + n\beta)$$

$$S(n) = O\left(\frac{n^2+n+n\log n+n^2/\log n+\log n}{n\log n+n^2+n+n\beta}\right)$$

Es decir, el tiempo asintótico no cambia, pero la cantidad de canales de comunicación total se reduce.
