## Pregunta 1 — Suma de números (2 pts)

Enviar un vector de tamaño $x$ de un proceso a otro demora $t(n) = (\alpha + x \cdot \beta)$, donde $\alpha$ es la latencia, y $\beta$ el ancho de banda.

#### (a) Determine $t_p(p, q)$

Determine $t_p(p, q)$ al calcular la siguiente suma con $p = 2^N$ procesos:

$$s = \sum_{j=1}^{q \cdot 2^N} y_j$$

$y_j \in \mathbb{R}^n$, $j = 1, ...q \cdot 2^N$

Considere que la suma de $n$ números tiene un tiempo secuencial $n \cdot t_a$ (donde $t_a$ es el tiempo empleado en hacer una suma). Además, debe considerar las operaciones de comunicación **(1 pt)**

### Solución

$T_s = nta$, $T_p = qta + p(\alpha + \beta) + p(\alpha + q\beta) + pta$

$qt_a$ es el cálculo por proceso, $p(\alpha + \beta)$ es la comunicación de las sumas parciales al maestro, $pt_a$ es la suma de los resultados parciales en el maestro.

#### (b) Determine la eficiencia $E(p, q)$

### Solución

$$S = O\left(\frac{nt_a}{qt_a + p(\alpha+\beta) + p(\alpha+q\beta) + pt_a}\right)$$

$$E = O\left(\frac{n/p \; t_a}{qt_a + p(\alpha+\beta) + p(\alpha+q\beta) + pt_a}\right) = O\left(\frac{1}{1 + p/qt_a(\alpha+\beta+q\beta+t_a)}\right)$$

¿En que casos se obtiene una eficiencia $E \ge 0.5$? Encuentre la condición en función a $p$ y $q$ para que esto suceda.

Utilizando: $E = \dfrac{1}{1 + p/qt_a(\alpha+\beta+q\beta+t_a)} > 0.5$, y transformando, obtenemos $q > p\dfrac{t_a}{\alpha+1}$

Determine $E$ para $\alpha = 1000$, $\beta = 10$, $N = 6$, $q=10,100,1000$ **(1 pt)**

Para $q=10$, $E=0.0001$

Para $q=100$, $E=0.0007$

Para $q=1000$, $E=0.0142$

Se comprueba la relación obtenida.

## Pregunta 2 — Escalabilidad (2 pts)

Las siguientes gráficas representan tiempo vs. número de nodos de un código de N-cuerpos (izquierda: 64K cuerpos, derecha: 512K). *(Gráfica: dos curvas de complejidad teórica — una decreciente y otra creciente — con puntos de cruce experimentales marcados con cruces rojas; a la izquierda para 64K cuerpos, a la derecha para 512K cuerpos.)*

#### (1) Puntos de cruce y proyección a N = 1M

¿Qué representan los puntos de cruce mostrados? ¿Cómo sería una gráfica para $N = 1M$ (un millón)? Realice en un gráfico speedup vs. nodos, el equivalente a los gráficos mostrados (inclusive N=1M) **(0.5 pts)**

### Solución

Los puntos de cruce representan el número óptimo de nodos por simulación. Aprox. 12 nodos para 64K cuerpos y aprox. 40 nodos para un millón de cuerpos. Para $N = 1M$ el punto de cruce se mueve arriba y a la derecha con respecto a los mostrados. I.e. punto óptimo de número de procesos.

#### (2) FLOPs teóricos

Se ha derivado una velocidad teórica en FLOPs para este modelo, de aproximadamente

$$V(n,p) \approx \frac{\gamma N^{2+x}}{\alpha N^{2+x}/p + \beta * \log p} \tag{1}$$

donde $\gamma = 500$ es el número de operaciones de coma flotante (FLOP) por partícula, por unidad de tiempo, $\alpha = 10^{-9}$, y $\beta = 1$ son constantes de hardware, $p$ es el número de procesos, y $x = 0.31$ es una constante experimental. Calcule los FLOPs teóricos de una aplicación de N-cuerpos en un supercomputador de 5000 nodos. ¿Considera, de acuerdo a la expresión obtenida, que la velocidad en FLOPs depende de $N$? **(0.5 pts)**

### Solución

Se obtiene $S = \dfrac{\gamma}{\alpha}p = 2.5$ PFLOP. No depende de $N$.

#### (3) Condición de escalabilidad

Derive la condición de escalabilidad para este modelo teórico **(0.5 pts)**

### Solución

$N^{2+x} \propto (\beta/\gamma)p\log(p)$

#### (4) Escalabilidad fuerte y débil

Realice un análisis de escalabilidad fuerte y débil con la expresión teórica obtenida **(0.5 pts)**

### Solución

Si $N$ es constante, $E \propto 1/p\log(p)$, por lo que no escala. Escalabilidad débil requiere la condición antes derivada.

## Pregunta 3 — Quicksort (2 pts)

Haga el análisis de complejidad del algoritmo paralelo quicksort mostrado, en el cual cada elemento de la lista es asignado a un proceso, en un paradigma de memoria compartida.

método QS(d,i,p):

Entrada: valor de (d) almacenado en la posición $i$, de un array de $n$ elementos

Salida: array ordenada de $n$ elementos

```
if(p=1) return
j:= random entre 1 y n
v:= d_j // pivot
f:=d ≤ v // booleano
j:= sum_{k=1}^{i} f_k // suma de prefijos
n' := j // evaluado hasta (n)
if (i < n') {
  // i pertenece a la partición izquierda
  QS(d,i,n')
} else {
  // i pertenece a la partición derecha
  QS(d,i-s,n-n')
}
```

#### (a) Complejidad

Calcule $W$, $T_\infty$, del algoritmo. Determine la complejidad del algoritmo en paralelo. $T_p(n,p)$. Asimismo, $S$ y $E$, y la condición de escalabilidad. Utilice la complejidad teórica de la suma de prefijos vista en clase **(1 pt)**

### Solución

$W = T_s = O(n\log n)$, $T_\infty(n) = T_\infty(n/2) + O(\log n)$, por lo que $T_\infty(n) = O(\log^2 n)$

$T_p(n,p) = O(n\log n/p + \log^2 n)$

$$S = \frac{n\log n}{n\log n/p+\log^2 n}$$

$$E = \frac{n\log n/p}{n\log n/p+\log^2 n} = \frac{1}{1+\log n*p/n}$$

por lo que la condición de escalabilidad es $p \propto n/\log n$

#### (b) Comunicación colectiva

Agregue un término de comunicación colectiva, como $T(p)=O(\log(p))$ (una mejora con respecto a la complejidad $O(p)$ vista en clase). Determine $S$ y $E$ bajo este supuesto. Llegue a una conclusión sobre la escalabilidad y compárela con el caso (a) **(1 pt)**

### Solución

$T_p(n,p) = O(n\log n/p + \log^2 n + \log p)$

$$S = \frac{n\log n}{n\log n/p+\log^2 n+\log p}$$

$$E = \frac{n\log n/p}{n\log n/p+\log^2 n+\log p} = \frac{1}{1+\log n*p/n+p\log p/n\log n}$$

por lo que existen dos condiciones de escalabilidad: $p \propto n/\log n$, $p\log p \propto n\log n$, siendo la segunda la relación dominante.
