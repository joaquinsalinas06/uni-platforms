## Pregunta 1 — p-Norma (2 pts)

La norma-1, 2, $\infty$, se define en un espacio n-dimensional:

$$\|x\|_p = \left(\sum_{i=1}^{n} |x_i|^p\right)^{1/p}, \quad \|x\|_\infty = \max_{i=1}^{n} |x_i|$$

#### (a) PRAM

Desarrolle un PRAM para el algoritmo. ¿Qué paradigma usa? **(0.5 pts)**

#### (b) Complejidad

Encuentre una expresión para $T_{comp}(n,p)$ y $T_{comm}(n,p)$. ¿Qué paradigma usa? **(0.5 pts)**

#### (c) Speedup y eficiencia

Determine el speedup $S(n,p)$, $E(n,p)$ **(0.5 pts)**

#### (d) Escalabilidad

Analice la escalabilidad en el cálculo en paralelo de la norma **(0.5 pts)**

### Solución

**a) Modelo PRAM (por proceso s):**

Ingreso: array $x$ de tamaño $n$, $p$ procesos con índice $1 \le s \le p$

Salida: valor de normas 1, 2, $\infty$

```
1. seed random_s
for 1 ≤ i ≤ n/p do
   a_i = random_s
endfor
2. for n/p(s) + 1 ≤ i ≤ n/p(s+1) do
   if(norma 1 o 2)
      norma += a_i o norma += a_i^2
   if(norma ∞)
      if(norma < a_i) norma = a_i
endfor
```

El PRAM representa el paradigma de paralelismo con memoria compartida.

**b) Indicadores PRAM:**

La comunicación consiste en:

Scatter: $O(p(\alpha + \frac{n}{p}\beta))$

Reduce: $O(\log p(\alpha + \beta))$

$T_{comm}(n,p) = O(p(\alpha+\frac{n}{p}\beta) + \log p(\alpha+\beta))$

El cómputo consiste en: $T_{comp}(n,p) = O(n/p)$

$$\therefore T_p(n,p) = O\left(\frac{n}{p} + p(\alpha+\frac{n}{p}\beta) + \log p(\alpha+\beta)\right)$$

**c)** Entonces, para este algoritmo se espera:

$$S(n) = O\left(\frac{n}{\frac{n}{p}+p(\alpha+\frac{n}{p}\beta)+\log p(\alpha+\beta)}\right), \quad E(n) = O\left(\frac{n/p}{\frac{n}{p}+p(\alpha+\frac{n}{p}\beta)+\log p(\alpha+\beta)}\right)$$

**d) Escalabilidad fuerte:** $n$ constante, $E = O\left(\frac{1}{p^2+p\log p}\right)$, por lo que se puede afirmar que no escala.

**Escalabilidad débil:** se obtienen las condiciones: $n \propto p^2$, $n \propto p\log p$, por lo que escala bajo la primera condición.

## Pregunta 2 — Multiplicación matriz-vector (1.5 pts)

El problema de la multiplicación matriz-vector tiene la siguiente complejidad teórica. En el caso del particionamiento por filas

$$T_p = \gamma(n^2/p) + \alpha\log(p) + \beta n$$

y en el caso del particionamiento por bloques

$$T_p = \gamma(n^2/p) + 2\alpha\log(\sqrt{p}) + \beta(n/\sqrt{p})$$

donde $\gamma$ es el tiempo de multiplicación/suma, $\beta$ el ancho de banda, y $\alpha$ el tiempo de latencia. Determine en cada caso (filas, bloques):

#### (a) Granularidad

¿Cuál de los métodos muestra mayor granularidad? Comente las ventajas/desventajas de éste método **(0.5 pts)**

### Solución

$$G_a = \frac{n^2}{p(n+\log(p))}$$

$$G_b = \frac{n^2}{p(n/\sqrt{p}+\log(\sqrt{p}))}$$

el particionamiento por bloques (b) muestra mayor granularidad (denominador es más pequeño), lo que es una ventaja al tener un overhead (comunicación) menor.

#### (b) Condición de escalabilidad

La condición de escalabilidad entre $n$ y $p$ para cada caso.

### Solución

a) $n \propto p$

b) $n \propto \sqrt{p\log(\sqrt{p})}$

#### (c) Método más escalable

¿Cuál de los métodos considera más escalable y por qué?

### Solución (como calculado en b)

a) $n \propto p$

b) $n \propto \sqrt{p\log(\sqrt{p})}$

En el primer caso, al duplicar $n$, obtenemos $p_2 \propto 2p_1$

El segundo caso, al duplicar $n$, obtenemos un valor menor, lo que lo hace más escalable, ya que cuando $n$ crece se requieren menos procesos para mantener la eficiencia constante.

## Pregunta 3 — DAG (1.5 pts)

Dado el siguiente procedimiento

```cpp
double sistema() {
double A[n][n], B[n][n], a, b, x, y, z;
ini(A,B);
a = tarea_1(A);
b = tarea_2(B);
s1 = suma_prefijos1(B,a);
s2 = suma_prefijos2(B,a,b);
z = s1 + s2;
return z;
}
```

La función ini() recibe dos matrices y las inicializa con valores generados internamente, con un costo de $2n^2$ flops. Los parámetros del resto de funciones son sólo de entrada (no se modifican). Las tareas 1 y 2 tienen un costo $O(n^2)$, la suma de prefijos tiene un costo $O(n)$.

#### (3.1) DAG y grado de concurrencia

Genere el DAG y señale su grado máximo de concurrencia (cantidad máxima de tareas simultáneas) **(0.5 pts)**

*(Figura: DAG con nodo raíz $T_1$ (ini), que se ramifica en $T_2$ y $T_3$ (tarea_1 y tarea_2, corriendo en paralelo), luego $T_4$ y $T_5$ (suma_prefijos1 y suma_prefijos2), que convergen en $T_6$ (la suma $z = s1+s2$).)*

### Solución

El grado máximo de concurrencia es 2 (las ramas $T_2$/$T_3$, y luego $T_4$/$T_5$, pueden ejecutarse simultáneamente).

#### (3.2) PRAM con memoria compartida

Genere un PRAM que resuelva el problema utilizando el paradigma de memoria compartida **(0.5 pts)**

```cpp
double sistema()
{
double A[n][n], B[n][n], a, b, x, y, z; // hilo 0
ini(A,B);
barrier();
a=tarea_1(A); || b=tarea_2(B);
barrier();
s1= suma_prefijos1(B,a); || s2= suma_prefijos2(B,a,b);
barrier();
z=s1+s2;
return z;
}
```

#### (3.2 cont.) Complejidad y speed-up

Determine la complejidad secuencial, en paralelo, y el speed-up en función de $n$ y $p$. Calcule la eficiencia del código, para una cantidad mínima de hilos **(0.5 pts)**

### Solución

$T_s = T_p = O(n^2)$, $S = O(1)$, $E = O(1/p)$, $E=0.5$ para $p=2$
