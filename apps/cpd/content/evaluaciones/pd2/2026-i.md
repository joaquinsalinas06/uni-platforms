## Pregunta 1 — Performance (2.5 pts)

Las siguientes gráficas representan tiempo vs. número de nodos de un código de N-cuerpos (izquierda: 64K cuerpos, derecha: 512K). *(Gráfica: dos curvas de complejidad teórica — una decreciente y otra creciente — con puntos de cruce experimentales (cruces) marcados; a la izquierda para 64K cuerpos, a la derecha para 512K cuerpos.)* Las cruces son datos experimentales. Las curvas continuas, son aproximaciones teóricas (según lo visto en clase).

#### (1.1) Puntos de cruce y proyección a N = 1M

¿Qué representan los puntos de cruce mostrados? ¿Cómo sería una gráfica para $N = 1M$ (un millón)? Argumente su respuesta **(0.5 pts)**

### Solución

Los puntos de cruce representan el número óptimo de nodos por simulación ($\approx 12$ para 64K cuerpos y $\approx 40$ para 512K). Para $N=1M$ el punto de cruce se mueve arriba y a la derecha con respecto a los mostrados. I.e. punto óptimo de mayor número de procesadores. Este punto óptimo puede calcularse proyectando las curvas según la formula de complejidad del algoritmo de N-Cuerpos.

#### (1.2) FLOPs teóricos

Se ha derivado una velocidad teórica en FLOPs para este modelo, de aproximadamente

$$FLOPs(n,p) \approx \frac{\gamma N^{2+x}}{\alpha N^{2+x}/p + \beta * \log p} \tag{1}$$

donde $\gamma = 500$ es el número de operaciones de coma flotante (FLOP) por partícula, por unidad de tiempo, $\alpha = 10^{-9}$, y $\beta = 1$ son constantes de hardware, $p$ es el número de procesos, y $x = 0.31$ es una constante experimental. Calcule los FLOPs teóricos de una aplicación de N-cuerpos en un supercomputador de 5000 nodos. ¿Considera, de acuerdo a la expresión obtenida, que la velocidad en FLOPs depende de $N$? **(0.5 pts)**

### Solución

Reemplazando datos, se obtiene 2.5 PFLOP. S depende ligeramente de $N$.

#### (1.3) Speedup y FLOPs

¿Cómo se relaciona el Speedup con la velocidad en FLOPs? **(0.5 pts)**

### Solución

El Speedup es proporcional a la velocidad en FLOPs, ya que $T_s \propto FLOP$.

#### (1.4) Escalabilidad

Analice la escalabilidad de este modelo teórico (considere escalabilidad fuerte y débil). Utilice la fórmula experimental para el Speedup **(1 pt)**

### Solución

$$E = O\left(\frac{1}{\frac{\alpha}{\gamma} + \frac{\beta p\log p}{\gamma N^{2+x}}}\right)$$

Escalabilidad fuerte: si $n$ no es constante, $E = O\left(\dfrac{1}{p\log p}\right)$

Escalabilidad fuerte: si $n$ crece, $E = O\left(\dfrac{1}{1+\frac{\beta p\log p}{\gamma N^{2+x}}}\right)$. Es decir, el algoritmo escala si se cumple que $N^{2.31} \propto p\log p$, o $N \approx \sqrt{p\log p}$

## Pregunta 2 — Árbol 2-3 (3 pts)

Un árbol 2-3 es aquel cuyos nodos internos tienen 2 o 3 hijos. Y todas las hojas están a la misma distancia de la raíz. A su vez, las hojas del árbol 2-3 están ordenadas. Mientras que para cada nodo interno, todo lo que está en un subárbol izquierdo es menor a lo que está en uno derecho.

*(Figura 1: Ejemplo de árbol 2-3 — árbol con una raíz de 2 hijos, cada uno con 2 o 3 hijos internos, y todas las hojas al mismo nivel, ordenadas de izquierda a derecha.)*

#### (2.1) PRAM y Span para búsqueda de m elementos

Elabore un PRAM y determine el Span para la búsqueda de $m$ elementos en el árbol 2-3 **(1.5 pts)**

### Solución

**Algorithm 1: Búsqueda paralela en árbol 2-3**

Input: Árbol 2-3 $T$, arreglo de consultas $Q[1..m]$

Output: Arreglo de resultados $R[1..m]$

```
for i ← 1 to m pardo
   R[i] ← BUSQUEDA23(T.raiz, Q[i]);
```

**Algorithm 2: Búsqueda recursiva en un árbol 2-3**

```
Function BUSQUEDA23(nodo, x):
if nodo = NIL then
   return falso;
if nodo.nclaves = 1 then
   if x = nodo.clave1 then
      return verdadero;
   else if x < nodo.clave1 then
      return BUSQUEDA23(nodo.hijo1, x);
   else
      return BUSQUEDA23(nodo.hijo2, x);
if nodo.nclaves = 2 then
   if x = nodo.clave1 o x = nodo.clave2 then
      return verdadero;
   else if x < nodo.clave1 then
      return BUSQUEDA23(nodo.hijo1, x);
   else if x < nodo.clave2 then
      return BUSQUEDA23(nodo.hijo2, x);
   else
      return BUSQUEDA23(nodo.hijo3, x);
```

#### (2.2) Métricas de $W$, $T_\infty$

Lea las métricas de $W$, $T_\infty$ del PRAM **(0.5 pts)**

### Solución

$W(h,m) = W(h-1,m) + O(m)$

$W(h,m) = O(mh) = O(m\log n)$

$T_\infty(h) = T_\infty(h-1) + O(1)$

$T_\infty(h) = O(h) = O(\log n)$

#### (2.3) $T_p$, $S$, $E$

Determine $T_p$, $S$, $E$ **(0.5 pts)**

### Solución

$$T_p = O\left(\frac{m\log n}{p} + \log n\right)$$

$$S = O\left(\frac{m\log n}{\frac{m\log n}{p}+\log n}\right)$$

$$E = O\left(\frac{\frac{m\log n}{p}}{\frac{m\log n}{p}+\log n}\right) = O\left(\frac{1}{1+\frac{p\log n}{m\log n}}\right) = O\left(\frac{1}{1+\frac{p}{m}}\right)$$

#### (2.4) Escalabilidad

Haga un análisis de escalabilidad del algoritmo **(0.5 pts)**

### Solución

**Escalabilidad fuerte:**

Si $m$ es constante, $E=O(1/p)$, es decir, no escala en forma fuerte

**Escalabilidad débil:**

Si $m$ crece, para $E=O(1)$, debe cumplirse $p \propto m$

## Pregunta 3 — Multiplicación de matrices (1.5 pts)

Considere el siguiente algoritmo (por proceso) de multiplicación de las matrices $A$ y $B$, almacenando el resultado en la matriz $C$, en memoria compartida

```
begin
    for each process Pi,j do
    begin
        C[i, j] := 0;
        for k := 0 to n - 1 do
          C[i, j] := C[i, j] +
            A[i, (i + j + k) mod n] x B[(i + j + k) mod n, j]
        endfor
    end
end
```

Cada matriz es de dimensiones $n \times n$. $t_c$ es el tiempo se suma/multiplicación de dos números.

#### (3.1) Complejidad en paralelo

Encuentre la expresión para la complejidad en paralelo **(0.5 pts)**

### Solución

Ya que, según el PRAM, cada proceso ejecuta un bucle lineal en $n$,

$$T_p = O((n^3/p)t_c + n)$$

#### (3.2) Speedup y eficiencia

Determine el speedup, y eficiencia del algoritmo **(0.25 pt)**

### Solución

$$S = O\left(\frac{n^3 t_c}{n^3/pt_c+n}\right), \quad E = O\left(\frac{t_c n^3/p}{n^3/pt_c+n}\right)$$

#### (3.3) Condición de escalabilidad

Determine la condición de escalabilidad **(0.5 pts)**

### Solución

$$E = \frac{1}{1+\frac{p}{t_cn^2}}$$

por lo que si $n$ es constante, $E=O(1/p)$ (no escala en forma fuerte)

Si $n$ crece, $E = \dfrac{1}{1+\frac{p}{t_cn^2}}$, por lo que escala en forma débil si $n \propto \sqrt{p}$

¿A qué modelo PRAM corresponde este algoritmo? **(0.25 pt)**

### Solución
