## Pregunta 1 — Normalización (2 pts)

Se muestran las operaciones de normalización sobre los elementos de una matriz $A[i][j]$:

$$sum = \sum_{i,j=1}^{n} A_{ij} \cdot A_{ji}$$

$$f = 1/\sqrt{sum}$$

$$A_{ij} = A_{ij} \cdot f$$

#### (a) PRAM

Desarrolle un PRAM para el algoritmo. ¿Qué paradigma usa? **(0.5 pts)**

#### (b) Complejidad

Encuentre una expresión para $T_{comp}(n,p)$ y $T_{comm}(n,p)$. Utilice comunicación optimizada, es decir, $f(p)=O(\log p)$ ¿Qué paradigma usa? **(0.5 pts)**

#### (c) Speedup y eficiencia

Determine el speedup $S(n,p)$, $E(n,p)$ **(0.5 pts)**

#### (d) Escalabilidad

Analice la escalabilidad en el cálculo en paralelo de la función de normalización **(0.5 pts)**

### Solución

**Modelo PRAM:**

Ingreso: matriz $A$ de tamaño $N \times N$

Salida: matriz $A$ normalizada

```
for 1 ≤ i,j ≤ n^2 pardo
   sum += A_ij · A_ji
endfor
f= 1/√sum
for 1 ≤ i,j ≤ n^2 pardo
   A_ij *= f
endfor
```

**b) Indicadores PRAM:**

$T(n) = O(n^2)$, $T(n,p) = O(n^2/p + \log p)$

se realiza una reducción global de complejidad $2*\log p(\alpha+\beta)$ (reducción + broadcast)

**c)** $S(n)=O\left(\dfrac{n^2}{n^2/p+\log p}\right)$, $E(n)=O\left(\dfrac{n^2/p}{n^2/p+\log p}\right) = O\left(\dfrac{1}{1+\frac{p\log p}{n^2}}\right)$

**d) Escalabilidad fuerte:** $n$ constante, $E = O\left(\dfrac{1}{p\log p}\right)$, no escala

**Escalabilidad débil:** $n$ variable, $E = O(1)$, si $n \propto \sqrt{p\log p}$ (escala bajo esta condición)

## Pregunta 2 — Multiplicación matriz-vector (1.5 pts)

El problema de la multiplicación matriz-vector tiene la siguiente complejidad teórica. En el caso del particionamiento por filas

$$T_p = \gamma(n^2/p) + \alpha\log(p) + \beta n$$

y en el caso del particionamiento por bloques

$$T_p = \gamma(n^2/p) + 2\alpha\log(\sqrt{p}) + \beta(n/\sqrt{p})$$

donde $\gamma$ es el tiempo de multiplicación/suma, $\beta$ el ancho de banda, y $\alpha$ el tiempo de latencia. Determine en cada caso (filas, bloques):

#### (a) Granularidad

¿Cuál de los métodos muestra menor granularidad? ¿Considera que por ello, este método tiene una ventaja sobre el otro? **(0.5 pts)**

### Solución

$$G_a = \frac{n^2}{p(n+\log(p))}$$

$$G_b = \frac{n^2}{p(n/\sqrt{p}+\log(\sqrt{p}))}$$

el particionamiento por bloques (b) muestra mayor granularidad (denominador es más pequeño), lo que es una ventaja al tener un overhead (comunicación) menor.

#### (b) Condición de escalabilidad

La condición de escalabilidad entre $n$ y $p$ para cada caso.

### Solución

a) $n \propto p$

b) $n \propto \sqrt{p\log(\sqrt{p})}$

#### (c) Método más escalable

¿Cuál de los métodos considera más escalable y por qué?

### Solución (como calculado en a)

a) $n \propto p$

b) $n \propto \sqrt{p\log(\sqrt{p})}$

En el primer caso, al duplicar $n$, obtenemos $p_2 \propto 2p_1$

El segundo caso, al duplicar $n$, obtenemos $p_2 \propto \sqrt[p_2]{(e^{60})}$, lo que lo hace más escalable, ya que cuando $n$ crece se requieren menos procesos para mantener la eficiencia constante.

## Pregunta 3 — DAG (1.5 pts)

Dada la siguiente función que realiza operaciones con los arrays $A$, $B$ y $C$:

```cpp
double OpArr(double A[], double B[], double C[], int n){
int i, j; double s1, s2, a, res;
suma_de_prefijos(A,n); // obtiene el array de suma de prefijos de A
quicksort(B,n); // ordena el array B
scan_left(C+x,n); // acumula los valores de elementos de C mas
// una constante x
for (i=0; i<n; i++) {    s1=0;
  for (j=0; j<n; j++) s1+=A[j]*B[j];
} // tarea 4
for (i=0; i<n; i++) { s2=0;
  for (j=0; j<n; j++) s2+=B[j]*C[j];
  } // tarea 5
 /* calculo final */
a=s1/s2; res=0;
for (i=0; i<n; i++) res+=a*C[i];
return res;
}
```

#### (3.1) DAG y grado de concurrencia

Genere el DAG y señale su grado máximo de concurrencia (cantidad máxima de tareas simultáneas) **(0.5 pts)**

*(Figura: DAG con tres nodos raíz en paralelo — $T_1$ (suma_prefijos, $O(n)$), $T_2$ (quicksort, $O(n\log n)$), $T_3$ (scan_left, $O(n)$) — donde $T_1$ y $T_2$ alimentan (arcos A, B) a $T_4$ ($O(n^2)$), y $T_2$ y $T_3$ alimentan (arcos B, C) a $T_5$ ($O(n^2)$); $T_4$ y $T_5$ convergen (arcos s1, s2) en $T_6$ ($O(1)$), que alimenta (arco a) a $T_7$ ($O(n)$), el cálculo final.)*

### Solución

El grado máximo de concurrencia es 3 (las tareas $T_1$, $T_2$, $T_3$ pueden ejecutarse simultáneamente).

#### (3.2 cont.) Complejidad, speed-up y eficiencia

Determine la complejidad secuencial, en paralelo, y el speed-up en función de $n$ y $p$. Calcule la eficiencia del código, para una cantidad mínima de hilos.

### Solución

$T_s = O(3n + n\log n + 2n^2)$

$$T_p = O\left(\frac{3n+n\log n+2n^2}{p} + n + n\log n + n^2\right)$$

$$S = O\left(\frac{3n+n\log n+2n^2}{n+n\log n+n^2}\right) = O(1), \quad E = O\left(\frac{1}{p}\right)$$
