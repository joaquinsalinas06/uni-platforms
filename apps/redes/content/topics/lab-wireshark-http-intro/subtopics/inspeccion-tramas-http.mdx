## 1. Idea

## 2. Dónde está cada dato (preguntas de la guía)

| Pregunta | Dónde mirar |
|---|---|
| Versión de HTTP del navegador y del servidor | Primera línea del GET y de la respuesta |
| Idiomas aceptados | Cabecera `Accept-Language` del GET |
| IP del computador y del servidor | Capa *IP*: `Src` y `Dst` |
| Código de estado | Línea de estado de la respuesta (`200 OK`) |
| Última modificación del archivo | Cabecera `Last-Modified` |
| Tamaño del cuerpo | Cabecera `Content-Length` o campo *File Data* |
| Cabeceras que el resumen no muestra | Bytes crudos del paquete |

El formato completo de petición y respuesta está en el tema de HTTP (Semana 2).

### Documento largo (archivo 3)

La respuesta no cabe en un segmento TCP: se ve **un GET** y **varios segmentos TCP** con datos, que Wireshark reensambla en una sola respuesta. Preguntas: cuántos GET se enviaron, qué código y frase devolvió el servidor y cuántos segmentos con datos hicieron falta.
