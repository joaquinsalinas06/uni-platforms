## 1. Idea

El DNS es una base de datos de **registros de recursos** (RR) con el formato

$$(\text{name},\ \text{value},\ \text{type},\ \text{ttl})$$

El significado de `name` y `value` depende del `type`; `ttl` es el tiempo de vida en caché.

---

## 2. Conceptos

| Tipo | `name` | `value` | Uso |
|---|---|---|---|
| **A** | nombre de host | dirección IPv4 | Traducir host a IPv4 |
| **AAAA** | nombre de host | dirección IPv6 | Traducir host a IPv6 |
| **NS** | dominio (p. ej. `foo.com`) | nombre del servidor autoritativo del dominio | Saber a quién preguntar por ese dominio |
| **CNAME** | alias | nombre canónico (el nombre "real") | Alias; p. ej. `www.ibm.com` es en realidad `servereast.backup2.ibm.com` |
| **MX** | dominio | nombre del servidor de correo (SMTP) asociado, con **preferencia** | Elegir a qué servidor enviar el correo |

En MX, el servidor con el **menor valor de preferencia** se contacta primero; si está caído, se usa el siguiente.

### Ejemplo de la hoja Ex 1 (pregunta 4)

```text
example.com.      MX    10 mail1.example.com.
example.com.      MX    20 mail2.example.com.
example.com.      NS    ns1.example.com.
example.com.      NS    ns2.example.com.
www.example.com.  A     93.184.216.34
example.com.      AAAA  2606:2800:220:1:248:1893:25c8:1946
```

1. **Propósito**: A y AAAA dan la IP (v4 y v6); NS indica los servidores autoritativos (`ns1`, `ns2`); MX da los servidores de correo y su orden.
2. **Acceso a `www.example.com` desde IPv4**: el registro **A** → `93.184.216.34`.
3. **Correo a `alice@example.com`**: consultar el **MX** de `example.com`; enviar al de menor preferencia (`mail1`, 10) usando el nombre que devuelve (cuya IP se resuelve con otra consulta A).
4. **Servidor no autoritativo**: los registros NS indican a qué servidores autoritativos preguntar (o derivar la consulta).
5. **`mail1` caído**: la preferencia 20 de `mail2.example.com` lo convierte en la alternativa.

---

## 3. Errores típicos

- Creer que el menor número de MX significa "menor prioridad": es el contrario, se contacta primero.
- Usar `A` para correo: el servidor de correo se obtiene con `MX`.
