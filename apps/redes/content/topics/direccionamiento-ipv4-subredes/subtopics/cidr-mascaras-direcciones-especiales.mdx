## 1. Idea

La notación decimal facilita leer una dirección, pero los límites de red están definidos en bits.

## 2. Conceptos

| Caso del material | Interpretación |
|---|---|
| 127.0.0.1 | Loopback: comunicación local |
| 255.255.255.255 | Broadcast limitado, todos los bits a uno |
| Dirección de red | Primera dirección del bloque: host a cero |
| Broadcast de subred | Última dirección del bloque: host a uno |

Para /23, el tercer octeto de la máscara es 254 (`11111110`). Un bloque empieza en un tercer octeto par y abarca dos valores consecutivos. /24 deja ocho bits host y la máscara es 255.255.255.0.

## 3. Ejemplo resuelto

Para 200.23.16.0/23 de la slide: prefijo de 23 bits, nueve host, $2^9=512$ direcciones. Red 200.23.16.0; broadcast 200.23.17.255. En una subred ordinaria que reserva ambos extremos, quedan 510 direcciones intermedias. Esta resta no se generaliza aquí a casos especiales no tratados en las slides.

## 4. Errores típicos

- Leer /23 como 23 direcciones.
- Confundir máscara con broadcast.
- Usar un OR con 255.255.254.0 y concluir que produjo el broadcast.
